# Ownership boundary

This repository contains academic/course material. The original report, notebook
contributions, supplied load/EV profiles and upstream code may have different
authors and terms. Public availability alone does not grant redistribution rights.

Before a release, confirm the author/team for each artefact, supplied-course terms,
input source/version, transformations and permitted licence. Do not infer sole
authorship from repository ownership. No blanket MIT licence has been added.

The 2026-08-30 documentation update records a reproduction plan only; it does not
claim that a later implementation was used for the original submission.
