# Reproducibility status

## What is currently published

The tracked repository contains Step 1 and Step 2 notebooks, their spreadsheets/results, and the course report. Later-step material exists in the local working tree but has not been reviewed for authorship, source-data rights, execution order, or reproducibility and is therefore not included in this open-source-readiness commit.

## Required before calling this runnable software

- identify the Python and pandapower versions used;
- document notebook execution order and expected runtime;
- record sources and reuse rights for the CIGRE network and load/PEV profiles;
- separate source inputs from generated results;
- restart kernels and execute every tracked notebook top-to-bottom;
- compare regenerated tables with the report;
- export a machine-readable environment and add automated smoke checks.

Until these gates pass, describe this as a technical/educational study rather than a reusable package.
